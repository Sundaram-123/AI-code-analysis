Supports Python, JavaScript, TypeScript, C, C++, Java, PHP, Go, Ruby, and SQL. You can paste code directly or upload a file. Issues with a clear, unambiguous mechanical fix (like "=" vs "==", or off-by-one loop bounds) show an "Apply fix automatically" button that edits your code directly. Issues that need judgment about intent (like choosing a type, adding business logic, or picking specific SQL columns) are flagged with a suggested fix for you to apply manually — a script can't safely guess those without understanding what the code is meant to do.
